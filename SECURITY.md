# Security Policy

## Reporting

Do not disclose privilege escalation, credential leakage, ADB authentication
bypass, or arbitrary command execution in a public issue. Report security issues

## Scope

The Android applications can use ADB, Shizuku, or Dhizuku capabilities. Grant
those permissions only to builds and source code you trust. Never commit ADB
private keys, signing keys, API credentials, device dumps, or personal data.
